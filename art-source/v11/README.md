# Crownshard V11 orb masters

These six 1024px chroma-key masters were generated for the Phoenix Ember,
Frostglass, and Nexus Crown collectible families. Runtime files are transparent,
trim-safe 256px PNGs under `public/assets/sprites/v11/`.

The game applies its six board-colour tints at runtime so each family keeps one
consistent material language without shipping duplicate source renders.
