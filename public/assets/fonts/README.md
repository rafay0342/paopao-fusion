# Bundled game typography

The game self-hosts two Google Fonts under the SIL Open Font License 1.1:

- **PaoPao Display** is the Latin variable build of [Cinzel](https://fonts.google.com/specimen/Cinzel), used at weights 600-700.
- **Fusion Sans** is the Latin variable build of [Sora](https://fonts.google.com/specimen/Sora), used at weights 400-700.

The WOFF2 files were retrieved from the official `fonts.gstatic.com` URLs exposed by the Google Fonts CSS API on 2026-07-21. The upstream license texts are available in the official Google Fonts repository at [Cinzel/OFL.txt](https://github.com/google/fonts/blob/main/ofl/cinzel/OFL.txt) and [Sora/OFL.txt](https://github.com/google/fonts/blob/main/ofl/sora/OFL.txt).

The local family aliases keep the product typography stable while preserving offline startup and system-font fallbacks.
